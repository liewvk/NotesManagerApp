# NotesManagerApp

NotesManagerApp is a C# application for creating, managing, and organizing notes.

## Features

- Create, edit, and delete notes
- Organize notes by tags or categories
- Simple and lightweight

## Requirements

- .NET 6.0 SDK or later (https://dotnet.microsoft.com/)

## Build and run

1. Open a terminal and navigate to the project directory (where the .csproj file is located).
2. Restore dependencies and build:

   ```bash
   dotnet restore
   dotnet build
   ```

3. Run the app:

   ```bash
   dotnet run
   ```

If the solution contains multiple projects, navigate to the desired project subfolder before running the commands above.

## Tests

If the repository contains unit tests, run them with:

```bash
dotnet test
```
